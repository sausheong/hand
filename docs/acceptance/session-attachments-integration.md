# Session attachment persistence, replay, fork and export

Unpublished Harness `d4b97f3eb310581d659c29560e046802979c146c` adds reference-backed images to persistent message and tool-result records. AppendContext writes verified immutable blobs before the referencing entry; blob failures preserve the old leaf and surface persistence failure. Runtime Run/RunTurn resolve references before assembling model input. Missing/corrupt blobs stop provider execution rather than silently omitting images. Unknown JSON payload fields survive transformation. In-memory sessions keep inline images.

The new blob directory's parent is synced before references can be published. The parent must already exist. Session JSONL remains bounded: a 12 MiB test image is represented by a small record, with content in the agent directory's private `.attachments` store.

Staged Hand copies referenced blobs into fork staging, then publishes required blobs into the destination store before the fork JSONL. Export copies only referenced blobs into a sibling `.attachments` directory before exclusive JSONL publication. Its 256 MiB limit includes JSONL plus unique referenced blobs. Failed/cancelled exports may leave reusable immutable sidecars but do not expose a partial JSONL. Missing source blobs prevent fork/export success. Existing exported sidecar directories can be shared by several exports; use a dedicated directory for a self-contained bundle.

To move an image-bearing export, copy its JSONL and sibling `.attachments` directory together. For `export.jsonl` in a directory, Harness `session.NewStore(directory).LoadExclusive("", "export")` can reopen it. The TUI success message and CLI flag help explain the sidecar requirement. Moving JSONL alone is insufficient.

Tests cover large-image restart/byte identity, reference-only records, tool payload preservation, failed writes, model replay, missing blobs and independent fork/export. The export journey removes access to the original blob store before reopening the copy and verifies that unrelated blobs were not exported. Session/replay regressions passed 20 race-enabled repetitions (120 test/subtest events); Hand workflows passed 20 repetitions (40 passes). After a final parent-directory durability correction, storage tests passed another 20 repetitions (100 passes), full suites passed 894 Harness and 586 Hand tests/subtests without failures/skips, and both vet runs passed. The initial compile error from an overly broad context edit is preserved and was corrected before passing evidence.
