These are required tests, not tests that already exist. Each scenario needs a reproducible check, an independent expected result and an evidence record. See [definition of done](definition-of-done.md). IDs are mirrored in [requirements.json](requirements.json). Every implementation-plan bullet must additionally map to an ID in the final traceability review; a matrix row alone does not prove the whole feature.
